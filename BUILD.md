# Build Macro Deck Pro Installer

Run this script after installing Inno Setup 6.

```powershell
.\build.ps1
```

Output: `MacroDeck.Setup\Result\macro-deck-pro-*.exe`

## Prerequisites

1. Install [Inno Setup 6](https://jrsoftware.org/isdl.php)
2. Install [.NET 8.0 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)
